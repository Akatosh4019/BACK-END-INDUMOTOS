# Corrección y papelera de guías

- Una guía activa conserva un número único, sin distinguir mayúsculas ni espacios exteriores. La base de datos impide duplicados incluso si dos personas registran a la vez.
- Solo una guía pendiente, sin motocicletas ni borradores, puede retirarse o recibir fotos nuevas. El retiro exige un motivo y registra usuario y fecha.
- La papelera permite restaurar durante 30 días. Si entretanto se creó otra guía activa con el mismo número, la restauración se bloquea hasta resolver el conflicto.
- Una tarea diaria elimina las fotos y sugerencias OCR de los registros retirados al vencer el plazo. La llegada y sus eventos de auditoría permanecen para consultar número, fecha, responsable y motivo.
- Reemplazar fotos descarta las sugerencias OCR anteriores; las nuevas fotos pasan por la misma validación de formato, tamaño, dimensiones y contraste que durante el registro.
- La vista previa ayuda al trabajador a comprobar que adjuntó la guía correcta. La validación automática no demuestra que una foto corresponda al número escrito; el trabajador debe revisarlo antes de guardar.

La retirada local anterior de la guía duplicada `TG01-38359` se registró como corrección del sistema sin atribuirla a un trabajador. Los datos de Docker locales no se distribuyen mediante Git.
